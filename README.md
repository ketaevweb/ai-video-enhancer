# AI Video Enhancer — «честный» Real-ESRGAN в реальном времени

Просмотр коллекции фильмов 480p/720p на 2K-мониторе (2560×1440) с обработкой
картинки нейросетью **Real-ESRGAN** на видеокарте **в реальном времени** — как
«ИИ-процессор» в телевизорах (апскейл + шумоподавление + детализация), только
честнее: используются оригинальные веса Real-ESRGAN, а не шейдеры-имитации.

```
видео 480p ──► VapourSynth ──► TensorRT (fp16, RTX 3080) ──► 3840×2160 ──► 2560×1440
                (конвейер)      RealESRGAN x4plus/x2plus      supersampling   вывод
```

В отличие от шейдерных решений (FSRCNNX, Anime4K, SSimSuperRes — «лёгкие»
свёртки, заточенные под скорость) здесь работает **полноценная RRDB-сеть
Real-ESRGAN x4plus (16.7 млн параметров)** — та же архитектура, что используется
в офлайн-обработке видео. Именно она «додумывает» детализацию и давит шумы так,
как это делают ИИ-процессоры телевизоров.

---

## Состав

| Компонент | Роль |
|---|---|
| [mpv](https://mpv.io) (сборка zhongfly, x86_64-v3) | плеер со встроенной поддержкой VapourSynth |
| [VapourSynth R81](https://github.com/vapoursynth/vapoursynth) | покадровый видеоконвейер |
| [vs-mlrt v15.13](https://github.com/AmusementClub/vs-mlrt) (TensorRT 10.13, CUDA 12.9) | нейроинференс на GPU |
| [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN) (ONNX, официальный) | модели: x4plus, x2plus, general-x4v3, wdn, animevideov3 |
| TensorRT fp16 движки (собираются на вашей машине) | максимальная скорость инференса под вашу GPU |

## Требования

- Windows 10/11 x64
- NVIDIA GPU (проект настраивался под **RTX 3080**; подойдёт любая NVIDIA 2018+)
- Драйвер NVIDIA **525 или новее** (используется CUDA 12.9)
- ~12 ГБ на диске (bundle TensorRT ~4 ГБ + mpv + модели + движки)
- Интернет на время установки, права администратора

## Установка (один клик)

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
   В папке `models/` могут лежать ONNX-модели из релиза — установщик подхватит
   их локально, если интернета под рукой нет.
2. Правый клик по **`install.bat` → «Запуск от имени администратора»**.
3. Ждите 20–40 минут: большая часть времени — **разовая** сборка TensorRT-движков
   под вашу видеокарту (RRDB-модели собираются по 5–15 минут — это нормально).
4. По окончании на рабочем столе появится ярлык **AI Video Player**.

Скрипт идемпотентный: перезапуск пропускает уже сделанные шаги. Можно
дозапускать с флагами: `-SkipEngines`, `-NoMpv`, `-NoShortcut`,
`-BaseDir D:\AIVideoEnhancer`.

## Использование

Просто открывайте фильмы в **AI Video Player** (mpv). Для источников с высотой
кадра ≤ 720p ИИ включается автоматически:

| Источник | Что происходит |
|---|---|
| 480p/576p (SD-тир) | кадр вписывается в 960×540 → **RealESRGAN x4plus ×4** → 3840×2160 → честный саперсемплинг до 2560×1440 |
| 720p (HD-тир) | кадр вписывается в 1280×720 → **RealESRGAN x2plus ×2** → ровно 2560×1440 |
| выше 720p | передаётся без обработки (ИИ там не нужен) |

Соотношение сторон сохраняется (анаморфные DVD 720×480 с SAR 32:27 → честные
854×480 → 1440p без искажений), цветовая матрица BT.601/709 определяется
автоматически, точность выхода — 8/10 бит по исходнику, дизеринг error-diffusion.

### Горячие клавиши (переключение на лету)

| Клавиша | Пресет | Модель (SD / HD) |
|---|---|---|
| `Ctrl+1` | **max** (по умолчанию) | RealESRGAN **x4plus** / **x2plus** — максимум детализации |
| `Ctrl+2` | **fast** | realesr-general-x4v3 — компактная, заметно быстрее |
| `Ctrl+3` | **denoise** | realesr-general-wdn-x4v3 — сильное шумоподавление (DVD/VHS-рипы) |
| `Ctrl+4` | **anime** | realesr-animevideov3 — для аниме и мультфильмов |
| `Ctrl+0` | выкл. ИИ | сравнение «до/после» |
| `b` | дебандинг | для сильно пережатых источников |
| `Ctrl+s` | скриншот | сохранить обработанный кадр |

## Бенчмарк и ожидаемая производительность (RTX 3080)

```powershell
powershell -ExecutionPolicy Bypass -File bench.ps1              # SD-тир, все пресеты
powershell -ExecutionPolicy Bypass -File bench.ps1 -Tier hd    # HD-тир
```

Ориентиры (TensorRT fp16, статические движки, CUDA Graphs; точные цифры даёт
только бенчмарк на вашей машине):

| Пресет (SD 480p → 1440p) | Ожидание на 3080 |
|---|---|
| fast (general-x4v3) | комфортный реалтайм, запас ×2 |
| **max (x4plus)** | реалтайм для кино 23.976 fps, при просадке — `Ctrl+2` |
| denoise / anime (компактные) | реалтайм с запасом |
| max (HD 720p, x2plus) | пограничный — если не тянет, используйте `fast` |

Подсказки: нехватка кадров появляется и уходит рывками звука/картинки — переключите
пресет на лету. На итоговый FPS также влияют `concurrent-frames` в mpv.conf
(по умолчанию 4; на 6/8 может быть быстрее) и `NUM_STREAMS` в `engine/enhance.py`.

## Как это работает внутри

1. mpv декодирует кадр и отдаёт его в VapourSynth (`--vf=vapoursynth`, скрипт
   `engine/enhance_mpv.vpy`, mpv сам отключает аппаратное декодирование).
2. Кадр вписывается (с сохранением DAR) в каноническую форму движка: SD 960×540
   или HD 1280×720, поля добиваются чёрным — движок всегда получает ровно ту
   форму, под которую собран (статический TensorRT-движок = максимальная скорость).
3. YUV → RGBS (float), корректная матрица BT.601/709 и ограниченный диапазон.
4. `core.trt.Model` — инференс Real-ESRGAN, fp16, CUDA Graphs, 2 CUDA-стрима.
5. Поля вырезаются, кадр масштабируется до 1440p по DAR, конвертируется обратно
   в YUV с дизерингом; таймштампы проходят насквозь (фильтры VapourSynth
   сохраняют свойства кадров).

Движки (`engines/*.engine`) собираются на вашей машине из ONNX-моделей утилитой
`trtexec` (`build-engines.ps1`): fp16 + статические формы + общий timing-cache.
Пересборка (смена GPU/драйвера): `build-engines.ps1 -Rebuild`.

## Свои модели

Любую `.pth`-модель Real-ESRGAN можно подключить:

```bash
pip install torch onnx
python tools/convert_pth_to_onnx.py MyModel.pth MyModel.onnx
```

Затем добавьте строку в `engine/engines.json` (форма входа = размер, под который
собирается движок) и запустите `build-engines.ps1`.

## Диагностика

| Симптом | Решение |
|---|---|
| mpv пишет «Could not open VSScript.dll» | переустановите VapourSynth (установщик R81), перезапустите плеер |
| «Движок не найден: ...engine» | запустите `build-engines.ps1` |
| Ошибка trtexec про драйвер/CUDA | обновите драйвер NVIDIA (нужен 525+) |
| Рывки, проседания FPS | `Ctrl+2` (fast), поднимите `concurrent-frames` до 6–8 в mpv.conf |
| Чересстрочный гребень (редкие DVD) | источник интерлейсный — прогоните через QTGMC заранее |
| Откат всего ИИ | `Ctrl+0` или запуск mpv с флагом `--vf=` |
